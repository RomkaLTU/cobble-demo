# Todo

A small todo list app for the team. Add tasks, tick them off when done and remove them. Tasks are kept in the browser's `localStorage`, so each browser has its own list and it survives a page reload.

Built with Vite, React and TypeScript.

## Commands

```sh
npm install     # install dependencies
npm run dev     # start the dev server
npm test        # run the unit tests (Vitest)
npm run build   # type-check and build into dist/
```
